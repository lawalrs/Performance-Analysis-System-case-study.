Project role
This notebook represents the team's PROJECT for junior analysts solution to the Portfolio Performance Analysis System case study.

What this notebook does
The system takes a portfolio (holding assets) stored as a list of dictionaries, calculates investment performance, checks data quality, studies allocation by asset type/sector/country, identifies simple risk flags, and produces a management summary.

Note: The dataset is fictional and designed for learning. Monetary values are kept in the supplied simplified units; currencies are included as descriptive fields rather than converted across exchange rates.
Final Note
This Performance Analysis System is a question-by-question learning solution and the integrated system. it is done by members of Team-D to show how each Python concept was solved and how they can be combined into a reusable mini-application system that tracks performance.
